# 中国大陆 App 备案 + App Store 中国区上架

> 字段名给「中文 / English」。备案表单是中文，ASC 常是英文。

## 第一步：先分流，别急着备案

**判定标准不是「上不上中国区 App Store」，而是「App 有没有境内网络请求」。**

先问清：
1. 运行时会发网络请求吗？（埋点、崩溃上报、SDK、远程配置、登录、加载 URL、iCloud…）
2. 有没有后端域名，且服务器在中国大陆？
3. 有没有付费、内购、广告、会员？

| 情形 | 是否需 App 备案 | 走哪节 |
|---|---|---|
| 完全零联网，功能全本地 | 不需要 | **A** |
| 有联网但后端在境外 | 严格意义不受工信部约束；隐私/支持页若用**境内域名**，该域名仍须网站备案 | 先试 **A**，兜底 **B** |
| 有联网 + 后端在境内 | **必须** | **B** |

硬线：豁免唯一判据是「零境内网络接入」。启动页埋点也算联网——虚假申报必驳。

---

## A. 零联网 App：申请 ICP 豁免

1. **自证零联网**（完整清单见 [`references/zero-network-proof.md`](references/zero-network-proof.md)）：静态依赖/出网 API 搜索、Info.plist/Entitlements、飞行模式可用、抓包 App 进程零出网，且同会话用 Safari 做阳性对照。
2. 填苹果豁免声明：Team ID + App ID + Bundle ID + 主体信息。
3. 个人：手写签字 + 身份证 + 日期（PDF 常拒，传照片/扫描）。
4. ASC → Contact Us → App Review appeal，英文写明全本地、无境内/远程联网。
5. 周期约 3 个工作日。证据多来自实务而非苹果明文；策略是「先可举证 → 再申诉 → 驳回再走 B」。

破功：加 iCloud/崩溃统计/任何网络请求 → 豁免作废，必须备案。

## B. 需要备案：APP 备案流程

### 两套号别混

| 类型 | 格式 | 例 |
|---|---|---|
| 网站备案号 | `…号-1` | `粤ICP备12345678号-1` |
| APP 备案号 | `…号-nA` | `粤ICP备12345678号-2A` |

同一主体/域名常可一张订单，但**号码是两个**。个人 vs 企业规则以接入商当期公示为准。

### 挂号位置（实操硬规则）

| 号码 | 挂哪里 |
|---|---|
| 网站 `…号-1` | **仅**网站脚底／站 chrome，链工信部查询 |
| App `…号-nA` | ASC 中国大陆 ICP 栏 + **App 内**关于／设置公示 |

**禁止**把 App `…-nA` 挂在网站正文中间；也禁止把网站 `-1` 填进 ASC App ICP 栏。

### 前提条件

| 项目 | 要求 |
|---|---|
| 域名实名 | 注册人与备案主体一致 |
| 接入商 | 境内云 ≥约 3 个月、公网 IP；**境外 VPS / Vercel / 海外 SaaS 不能作接入** |
| 主体实名 | 在该云厂商完成 |
| 备案服务号 | 控制台生成；无号进不了提交页 |
| App 展示名 | 与 ASC 简体中文名一致 |
| Bundle ID + 公钥 + SHA-1 指纹 | 从 **Distribution** 证书提取；表单写 MD5 时 Apple 填 SHA-1 hex；**绝不编造** |
| 图标 | 部分厂商 ≤100KB |
| 隐私／支持 URL | 可访问；页在境外托管本身可不备案，但境内域名解析到它则域名要备 |
| 承诺书 | 个人手写签字 + 身份证 + 日期 |

### 典型顺序

1. 境内机（如腾讯云轻量 + 宝塔）；防火墙 80/443/22（+ 面板端口常 8888）。
2. 云厂商 ICP 控制台开 APP 服务；同域有网站则同单加网站，勿在缺网站备案时硬「继续提交」。
3. 填 Bundle／公钥／指纹／服务简介等。
4. 接入商初审 → **工信部短信核验（常 24h 内必须完成）** → 省管局 7–20 工作日 → 个人常需人脸核验。
5. 合计最快约 3–5 天，常规 2–4 周；部分厂商订单约 45 天有效。
6. 拿号后：ASC 回填 `…-nA` + App 内公示；网站挂 `…-1`。
7. 可选下一版：境内反代 `api.` 域 → 境外 SaaS；原生 API 基址变更通常要新包重审。

### 表单要点（摘）

- App 服务内容：官方目录选近项 + 备注写清真实用途。
- 是否提供／应用 SDK：自研 SDK 供他人才「提供」；用了支付/登录等要列厂商与类型。
- 域名：用到几级备几级，最多四级。

### 个人主体硬限制

个人 = **非经营性**。一般不能商品交易、会员充值、付费订阅、广告变现。若产品未来要收费，**备案阶段就用企业主体**。

## C. ASC 与备案时间配合

- 备案与 Apple 审核可并行。
- 推荐：先境外后端过审 → 备案齐后下一版切境内代理。
- 境内代理价值：合规 + 降低直连被墙境外 SaaS 域名的风险。

---

## D. Ready for Sale 但搜不到（实操）

`READY_FOR_SALE` / `downloadable=true` **不够**。

1. **价格与销售范围 / Pricing and Availability**：目标国家（含中国大陆）已勾。
2. **中国大陆 ICP**：App 号已填且关联可上架。
3. 公开核验：`https://itunes.apple.com/lookup?id=<AppleID>&country=cn` → `resultCount>0`；`https://apps.apple.com/cn/app/id<AppleID>` 应是 App 页，不是 404／落到 Today。
4. 配置正确后索引仍可能数十分钟～48h；若 CN 直链长期 404 且全球 lookup=0，按 **开区／ICP** 排，不要只当成「传播中」。

---

## E. 版本火车（过审后）

- 某短版本（如 `0.1.0`）过审且 train 关闭后，**不能**再传同 `CFBundleShortVersionString` 的包（ITMS-90186 / 90062）。
- 升短版本（如 `0.1.1`）并递增 build；仅 TF 也一样。

---

## F. 大陆机／宝塔运维备忘

- 面板地址常为 `http://<IP>:<port>/<安全入口>`（根路径常 404；未开面板 SSL 时用 http）。
- 面板内改密失败 → 云控制台「应用管理／重置面板密码」。
- Vault 若要求 https 站点，裸 `http://IP` 可能存不进——改用 SSH／面板 SSL，或工程 1:1 交密；勿贴群聊。

## 常见死法

| # | 死法 | 后果 |
|---|---|---|
| 1 | 境外机当接入 | 驳回 |
| 2 | 域名实名人 ≠ 主体 | 退回 |
| 3 | `-1` / `-nA` 填反或网站挂 App 号 | 驳回／违规展示 |
| 4 | App 内不公示备案号 | 复查下架 |
| 5 | 换域／换主体／服务器到期未变更备案 | 失效 |
| 6 | 名称等变更 30 日内未办变更 | 整改 |
| 7 | Ready for Sale 但未开销售国家／未填 ICP | 搜不到 |
| 8 | 过审后同短版本再传包 | ITMS-90186/90062 |

## 术语

备案＝登记非许可；接入商＝代交的境内云；备案服务号＝提交凭证；管局＝省通管终审；豁免＝零联网向苹果免填 ICP。
